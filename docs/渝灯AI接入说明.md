# 渝灯夜话

在六关正常游玩时按 **F** 打开，输入问题后回车或点发送；**Esc / 收起** 关闭。打开期间关卡暂停，关闭后继续。剧情对话、漫画、操作冻结、设置暂停期间不抢占输入。

渝灯主动问候；支持重庆科普、游戏设定与操作解释、当前目标提示。快捷问题可直接点选。同一章节保留最近六轮问答，换章节或点清空重置；不把聊天内容持久化到存档。AI只返回文字，不能修改游戏状态或执行代码。重庆知识可能出错，界面明确提示回复仅供参考。

## 模型与费用边界

2026-10-17更新：不再锁定智谱。F → AI设置可填写HTTPS基础地址或完整`/chat/completions`地址、模型ID及自己的密钥，适配采用Bearer认证、messages/choices结构的OpenAI兼容文本聊天服务，不是所有厂商的原生协议都能直接使用。UI显示配置的域名/模型，不能据此证明服务内部真正运行的模型。自定义服务可能收费，需用户自行确认；不自动回退智谱，也不自动探测模型或发送测试请求。更换地址必须重新输入密钥；密钥加密负载绑定接口地址，地址被修改时拒绝解密使用。此处“OpenAI兼容”仅指接口格式，不要求使用OpenAI服务。

“智谱预设”保留原HTTPS接口与 `glm-4.7-flash`；仅此预设返回 `429 / 1305`（模型访问量过大）时，尝试一次 `glm-4-flash-250414`。自定义模型不套用智谱特有字段、错误码逻辑或免费承诺。不对账号限流、认证失败或欠费自动重试，不充值。

核对日期：2026-10-16。官方定价页将这两个模型的文本输入/输出列为免费；提供方政策后续可能变化，发布前需复核。

每次输入最多300字符，最多输出650 tokens；一次只发一条请求，40秒超时；关闭窗口取消在途请求，不跟随HTTP重定向。

## 密钥与隐私

玩家在聊天窗“密钥”菜单输入自己的Key。未配置时自动展开输入；输入始终遮蔽，不回填已保存Key，禁用复制/剪切快捷键和右键菜单，提供专门粘贴按钮（不擅自修改系统剪贴板）。隐藏设置、保存或关闭时立即清空输入。可选“仅本次”（不写文件）或“保存本机”，也可删除已保存的本机密钥。优先使用当前会话/本机配置，其次使用进程环境变量 `ZHIPU_API_KEY`。源码、Git、导出包不包含开发者Key。

Windows使用DPAPI CurrentUser加密，密文保存在Godot用户目录 `user://yudeng_ai.cfg` 的 `[zhipu] dpapi_current_user`。启动时自动将旧版明文配置迁移为用户绑定密文，保留本机已配置的默认Key；迁移失败不会删掉旧文件，需手动重新保存成功后确认移除旧明文配置。新保存加密失败时只在内存使用，不退回明文。其他平台暂只支持本次使用。保护/解密通过隐藏PowerShell进程的标准输入输出管道传递，密钥不进入命令行参数，不输出到日志。此保护不防当前用户权限下的恶意程序、调试器或管理员读取运行内存，不承诺绝对保密。不要共享用户目录；轮换已贴在聊天中的密钥。比赛分发时由每位玩家提供自己的Key，不需要部署后端。

仅发送系统角色设定、玩家输入、最近问答、当前章节/目标以及染布百分比；不上传文件、完整存档、设备信息或个人身份。UI显示此提示。API密钥仅用于Authorization请求头，错误日志不输出请求头、密钥或原始服务端错误。
