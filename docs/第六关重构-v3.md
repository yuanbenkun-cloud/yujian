# 第六章：城市还记得（2026-10-14）

## 当前流程

1. 渝灯将前五关收集的旧时记忆带入想象中的未来重庆，发现普通人的记录被错误归为无用数据。
2. 主角越过两段维护路障，在26秒内跳近无人机接回记忆。R可重试，超时只恢复本段。
3. 记忆终端：连按接通供电、按住克服三段信号阻力、三次对准广播脉冲。键盘和鼠标均可操作。
4. 开启历史视角找到阿明、老周、周叔，恢复窑场、托付与引路灯的故事。市民使用独立待机和六帧行走，脚线与主角一致。
5. 两道供能门只在现实层按E接通；扫描区在历史层安全。灯芯在历史层每秒消耗6，在现实层每秒补充22。开门额外补充35。
6. 招募三人、开启两门、主角到集合点且队尾也越过安全线，才进入辨认阶段。扫描同时检查主角和队尾。
7. 两个节点统一标为A/B，先观察两边生活线索，再按E确认当前节点。误选可重新观察，不强制重玩整关。
8. 三种结局：档案柜封存人物、效率覆盖让残影消退并加快轻轨、公共记忆让人物继续走动并点亮步道。
