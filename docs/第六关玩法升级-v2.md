# 第六关玩法升级 v2

本轮替代v1的“过热长按传输”，保留18秒追逐、四次逐渐收窄的同步、能源限制和三个扫描区域。

## 解锁

GameState持久化completed_levels；正常通过逐关记入，完成第五关不自动补齐前四关。主菜单和LevelManager统一调用can_enter_future，五项齐全才显示并接受第六关请求。已验证资格重玩章节不丢失。

2026-10-17纠正：旧存档不自动推算已通过。无clear_records_version=2的记录原文件先备份为story_save.cfg.before_verified_clears.bak，其他剧情数据不清除。隐藏Ctrl+Enter现在明确作为“测试通关”记入当前关卡，逐关跳过五关后可解锁，但单独跳第五关仍不会补齐前四关。正常出口根据当前场景确定关号，避免F6或恢复时关卡管理器旧关号漏记。用户已明确确认五关全通的本次存档单独备份、修复，不作为通用自动解锁逻辑。

## 玩法区别

终端：供电 → 九宫格线路重构 → 四次同步。旋转弯管/直管，沿互相连接的端口把左侧旧档案送到右侧公共记忆。入口连通的线路不许断口、越界；无关支路不强制对齐。初始盘面确定且可解，可重置，验证失败只提示，不罚重打。支持鼠标、方向键导航与回车。界面沿用深蓝、金边、青色信号线，不需要新增生成图片。

护送：C让全队原地等候，再按恢复跟随。玩家能安排队伍在安全区休整，独自探路、开门或判断补能位置。人物等候时站立，不平移；扫描仍检查队伍而不是只检查玩家，不能把队伍留在危险区钻空子。HUD持续显示等候/跟随，短提示说明命令；失败自动清理命令，集合要求恢复跟随。
