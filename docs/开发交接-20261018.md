# 渝见 · 开发交接包

这是供其他开发者继续修改的完整 Godot 源码工程，不是只有安装程序的试玩包。本次仅整理、筛除开发无关文件，没有修改游戏玩法。

## 从哪里开始

- `01-源码工程/project.godot`：使用 **Godot 4.7.2 stable** 导入，等待资源首次导入完成，按 F5 运行全游戏。主入口为片头；单独打开某关 `.tscn` 后按 F6 可调试该关。
- `02-Windows试玩/渝见.exe`：最新试玩版。必须与同目录的 `渝见.pck` 一起保留，解压后再运行，无需安装。源码原导出名仍为“洞见”，只是历史文件名，游戏名是“渝见”。
- `版本与修改入口.md`：当前功能与技术细节。该文档中的旧构建目录、Build/Game多副本与备份路径是原工作区历史记录，不是本包缺失内容；本包只提供一套最新试玩版。
- `文件清单-SHA256.json`：打包时的文件清单、大小及校验值。不包含后续首次导入生成的缓存。

## 版本内容

五关主线通关后解锁第六关；包含未来关现实/回忆切换、线路谜题、队伍护送及三种结局。已包含主角/阿姨的新八帧步态、六关时空字幕、精灵平滑飞到前方、第四关精灵照明及最新用户提供的第六关BGM《星河回响》（60秒版）。

操作：A/D移动、空格跳跃、E互动、Esc设置、F精灵问答。第六关Q切换现实/回忆，C切换队伍跟随/等候。

开发用隐藏键 Ctrl+Enter 跳过当前关，作为“测试通关”记入存档；逐关跳完前五关可以解锁第六关。正式比赛是否保留测试快捷键由后续团队决定。单关测试不会自动证明前五关完成，不要把菜单未显示第六关误判成按钮故障。

## 重新导出 Windows

安装 Godot 4.7.2 对应 Windows 导出模板。终端在源码工程目录运行：

```powershell
New-Item -ItemType Directory -Path Build/Game -Force
& '你的Godot控制台程序完整路径.exe' --headless --path . --export-release 'Windows Desktop' 'Build/Game/洞见.exe'
```

建议也可在编辑器“项目→导出”使用已有 Windows Desktop 预设。导出文件夹必须先存在。EXE和PCK同名且同目录；改名应成对改名。本精简源码已在无原缓存的新目录完成首次导入、重新导出，并通过六关资源检查、主角动作及用户BGM测试。首次导入期间可能先出现字体导入缓存尚不存在的提示，等待资源导入完成后再运行；不要从原作者机器复制 `.godot`。

当前采用项目默认Forward+路径，不能承诺所有低配机器兼容；兼容渲染回退请后续团队单独测试。

## AI、隐私与授权

- 核心游戏不要求提供API Key。问答为可选功能，玩家自行配置服务地址、模型和自己的密钥；平台可能收费。
- 不附带开发者API Key、本机AI配置、进度存档、聊天记录、`.env`或Git历史。Windows保存密钥使用当前用户DPAPI，不能复制他人的配置当通用密钥使用。
- 游戏在 `user://` 保存配置与进度，通常位于Windows APPDATA下的Godot用户数据目录。接收方首次运行使用其本机存档；本包不会携带作者进度。
- 保留资源授权说明。用户提供的音乐和AI生成素材仍需项目方按比赛要求确认来源、使用权及披露方式，不能把本包视为授权审查结论。
- 源码调试版有本机MCP桥，默认只监听127.0.0.1:9090；Release不启用监听。无需该功能可在项目自动加载列表关闭McpInteractionServer，不必改游戏逻辑。

## 清理范围

交接包不含 `.git`、`.godot`、预览截图、临时音频候选、重复EXE/PCK、所有旧构建、无关学习项目或过时的大批原始立绘。保留当前运行资源、`.uid`、必要`.import`、授权文本以及最近动作源资料。

原工作区的清理采用可恢复归档，非永久删除。归档位于原项目 `Build/清理备份-20261018/`，其中 `恢复清单.json` 记录原路径与归档位置。若需要早期原图或旧包，可从该目录按记录拷回；不必把该大目录一并发给修改者。原工作区 `art_source/` 其他创作历史也仍保留，只是不放进本次精简交接包。
